# 08. 현재 빌드 기획서 (As-Built)

> 지금 **실제로 구현·동작하는** 게임을 역으로 정리한 문서다. 수치는 코드/에셋의 현재 값이며, 밸런싱·확장 논의의 기준점으로 쓴다. (앞을 내다보는 계획은 `05-roadmap.md`, 이 문서는 "지금 상태")
> 기준: UI 폴리싱 + 조준/이동 다양성 패스 · 테스트 109/109 (EditMode 96 + PlayMode 13) · 200체 @193fps

---

## 1. 한 줄 요약

탑다운 쿼터뷰 3D 뱀파이어 서바이벌류. 플레이어는 WASD로 움직이며 **무기는 자동 발사**, 몰려드는 적을 처치해 **경험치 젬**을 모으고, 레벨업마다 **업그레이드 3택**으로 강해지며 **5분 생존**을 노린다.

## 2. 조작

| 입력 | 동작 |
|------|------|
| WASD / 방향키 / 게임패드 좌스틱 | 플레이어 이동 (XZ 평면) |
| (자동) | 무기 발사 — 사거리 내 최근접 적을 자동 조준 |
| 마우스 클릭 | 레벨업 카드 선택 / 종료 화면 "다시 시작" |

## 3. 게임 플로우

```
시작(Game 씬) → 플레이(자동전투·생존)
   ├─ 적 처치 → XP 젬 드랍 → 자석 흡수 → 경험치
   │     └─ 레벨업 → [일시정지] 업그레이드 3택 → 선택 → 재개 (강해짐)
   ├─ 플레이어 HP 0 → 게임 오버
   └─ 5분 생존 → 생존 성공(승리)
종료 화면 → "다시 시작"(씬 리로드)
```

상태 기계(`GameDirector`): `Playing / LevelUp / GameOver / Victory`. LevelUp·종료 시 `Time.timeScale = 0`.

## 4. 플레이어

| 스탯 | 값 | 비고 |
|------|----|----|
| 최대 체력 | 100 | `PlayerDefinition` |
| 이동 속도 | 6 | 런타임 `RunStats`로 업그레이드 반영 |
| 자석 범위(pickupRadius) | 2.5 | 젬 흡수 반경 |
| 이동 방식 | Rigidbody(키네마틱) MovePosition | XZ 평면, 대각 정규화 |
| 이동 경계 | 아레나 ±59 clamp + 장애물 SDF 밀어내기 | 둘레 벽 + 내부 장애물 비침투(적과 동일 `ObstacleField`) |
| 비주얼 | **Crystal 스킨드 캐릭터** + Idle/Walk 애니메이션 | 아래 캐릭터/애니메이션 참고 |

- **캐릭터/애니메이션(Mecanim):** `Player` 하위 비주얼에 **Crystal 스킨드 메시**(Generic 리그 5본) + Animator. `Crystal.controller`의 **1D 블렌드 트리(`Speed`)** 가 Idle↔Walk를 섞고, `CharacterVisual`이 부모 이동량으로 `Speed`(0~1)를 구동 + 진행방향으로 회전(이동 로직과 분리된 표현 셸 → 입력 주체가 누구든 동일 동작). 루트모션 off(이동은 코드 구동).
  - **Generic 멀티-FBX 정석:** 메시 FBX가 아바타(`CrystalAvatar`) 생성 → 애니 FBX(Idle/Walk)는 **Copy From Other Avatar → CrystalAvatar**로 아바타를 공유해야 클립이 메시에 정확히 바인딩(미통일 시 T포즈). 텍스처 8K→2K(Base sRGB·Normal), 머티리얼 `Crystal.mat`(URP/Lit).

## 5. 카메라

Cinemachine 쿼터뷰. 플레이어 추종(Follow) + 항상 바라봄(HardLookAt). 오프셋 `(0, 14, -12)` → 약 45° 내려다보기.

## 6. 적 (3종)

스폰 시 플레이어 주변 반경 18 링에서 등장 → 중앙 시뮬레이션이 흐름장(seek) + **PBD 군중 솔버**로 이동. 접촉 시 플레이어에 초당 데미지.

| 종류 | 체력 | 이동속도 | 접촉 DPS | XP | 크기(scale) | 색 | 성격 |
|------|------|---------|---------|----|-----------|----|----|
| Chaser | 10 | 3.0 | 5 | 1 | 1.0 | 빨강 | 기본 트래시 |
| Swift | 6 | 5.0 | 3 | 1 | 0.7 | 빨강 | 빠르고 약함 |
| Brute | 30 | 1.8 | 10 | 3 | 1.5 | 빨강 | 느리고 단단 |
| **Bruiser**(강습병) | 55 | 3.2 | 12 | 1 | 1.2 | 주황 | 카이팅 따라붙는 맷집(후반) |
| **Charger**(돌격병) | 35 | 5.5 | 12 | 1 | 0.9 | 보라 | 빠르고 단단한 추격(후반) |
| **Tank**(중장갑) | 120 | 1.6 | 16 | 1 | 2.0 | 암적 | 안 녹는 벽(후반) |

- 후반 강한 적 3종은 **135초(압박)부터 점증 투입**, XP=1로 통일(처치 비효율 → snowball 자연 억제). 무기 만렙 후 "녹아버리는" 문제 대응.
- 비주얼: 캡슐(종류별 단색 머티리얼 → 종류당 GPU 인스턴싱 배칭). 기본 3종 빨강, 신규 3종 색 구분.
- AI: `EnemySimulation`이 매 FixedUpdate에 전체 적을 한 번에 갱신(데이터 지향, 얇은 셸). 이웃 질의는 `SpatialHashGrid`(물리 미사용).
- **군중 이동(PBD 통합 솔버):** `CrowdSolver` — Position-Based Multi-Agent Dynamics(Weiss/Karamouzas, MiG 2017) 정석 구현. 과거의 휴리스틱 더미(힘 separation·벽 접선 투영·개별 위치 보정·하드 클램프·step clamp)를 **하나의 위치 제약 투영**으로 통일. 흐름:
  1. 속도 블렌딩 `v=lerp(v_prev, v_pref, α)` → 예측 위치 `x*=x+v·dt`
  2. 이웃 탐색(예측 위치 기준) → 안정화 1회 + 주반복 6회 Jacobi delta-averaging(SOR 1.2)
  3. 제약: **적-적 비침투(마찰 접촉) + 적-벽 비침투(무한 질량, 동일 제약) + 장거리 예측 회피(time-to-collision)**
  4. 속도 복원 `(x*-x)/dt` → XSPH 점성 → 최대 가속/속도 클램프
  - **'밀지 않음 / 공간 없으면 정지 / 벽 비침투'가 하드 제약에서 자연 발생**(별도 if-휴리스틱 없음). 적-벽과 적-적이 같은 제약 형태.
  - 검증(100마리×200스텝): 벽 침투 0 · 적층 없음(최근접쌍 0.855) · 속도 튐 없음(2.19/cap 4) · 벽에 붙은 목표에 끝까지 접근(최근접 0.434).
- **벽 충돌(해석적 SDF):** `ObstacleField` — 축정렬 박스(AABB) 집합의 해석적 거리·법선. 격자 거리장과 달리 **연속**이라 벽 근처 떨림이 없다(격자 SDF 대비 변위 표준편차 0.150→0.000). `FlowFieldController`가 `NavObstacle` 박스로 구성해 `ServiceLocator`에 등록 → 솔버의 벽 제약에 공급.
- **네비게이션(NavMesh 미사용):** `FlowField`(그리드 비용장→방향장, BFS) — **선호속도(전역 라우팅) 소스**로만 사용(충돌 아님). `FlowFieldController`가 영역(120×120, 셀1)·장애물(`NavObstacle`)을 차단 셀로 표시하고 플레이어 셀 변경 시 재계산. **윈도우 BFS**: 목표 주변 반경 40셀 창만 계산 → 적은 항상 플레이어 근처(스폰 ≤28)라 창 밖 불필요, **재계산 비용이 맵 크기와 무관하게 일정**(120²에서 윈도우 1.98ms vs 전체 4.2ms, 에디터). 창 밖은 직선 추적 폴백. 디버그 기즈모 토글 제공.
- **아레나:** 둘레 벽 4개(NavObstacle, ±60, 내벽면 ±59, 두께 2)로 120×120 폐쇄 공간 → flow 격자(120×120)와 일치. 바닥 120×120. 플레이어는 ±59 clamp + 장애물 SDF로 항상 격자 안.
- **레벨 디자인(ProBuilder, 미로 아님):** 열린 중앙 + 흩어진 석재 구조물 12개(`Obstacles` 하위, 공용 머티리얼 `ObstacleStone`) — 코너 모놀리스 4(높이5, C2 회전대칭) + 변 슬래브 4(높이3) + 내부 기둥 4(4×4, 높이6). 전부 축정렬 박스(AABB 충돌·흐름 차단 정확). 넓은 통로·카이팅 피벗, 흐름 라우팅 showcase. 모두 `NavObstacle`이라 적·플레이어가 우회·충돌.
- 접촉 데미지: 적이 접촉 반경 내면 플레이어에 초당 데미지 적용.

## 7. 스폰 (Scenario_5Min — 5분 시간축 시나리오)

`SpawnScenario`(SO)가 경과 시간으로 `EnemySpawner`를 구동한다. **단계(Phase)** = 시각별 간격/최대생존/적 구성 가중치, **버스트(Burst)** = 특정 시각 일회성 무리 스폰(정상 상한 무시, 풀 한계까지). 시나리오 미지정 시 기존 `WaveDefinition` 단순 스폰으로 폴백.

**단계(steady, 점증 밀도 + 구성 변화)**

| 시작 | 라벨 | 간격 | 최대생존 | 구성(가중치) |
|------|------|------|----------|--------------|
| 0:00 | 워밍업 | 0.16s | 100 | 추격자 1.0 |
| 0:30 | 무리 형성 | 0.10s | 180 | 추 0.7 / 스위프트 0.3 |
| 1:15 | 쇄도 | 0.07s | 300 | 추 0.5 / 스 0.35 / 브루트 0.15 |
| 2:15 | 압박 | 0.05s | 440 | 추 0.35 / 스 0.30 / 브 0.15 / 강습 0.15 / 돌격 0.05 |
| 3:20 | 고밀도 | 0.04s | 600 | 추 0.25 / 스 0.25 / 브 0.15 / 강습 0.20 / 돌격 0.10 / 탱크 0.05 |
| 4:20 | 클라이맥스 | 0.03s | 800 | 추 0.15 / 스 0.20 / 브 0.15 / 강습 0.20 / 돌격 0.15 / 탱크 0.15 |

**버스트(일회성 스파이크)**: 0:45 스위프트×60 · 1:30 브루트×30 · 2:30 강습병×40 · 3:30 돌격병×50 · 4:15 탱크×25 · 4:50 탱크×40 + 돌격병×60(동시). 버스트는 정상 상한 무시(풀 max 2000까지).

- **스폰 위치(화면 밖 + 아레나 안):** 플레이어 주변 링에서 각도·거리를 뽑아 **아레나(스포너 `_arenaHalfExtent`=±58)로 clamp** → **카메라 화면 밖**(뷰포트 밖, 여유 4%)이고 **장애물 밖**이며 플레이어로부터 ≥9인 위치만 채택(거부 샘플링 24회). 링 반경은 단계별(워밍업 16, 이후 18~20).
- **순수 선택 로직:** `SpawnSchedule`(UnityEngine 비의존) — `PhaseIndexAt`(시각→단계), `WeightedIndex`(가중치 누적분포 선택). EditMode 12테스트.
- 경과 시간(`_elapsed`)은 `Time.deltaTime` 누적 → 레벨업/사망 시 timeScale=0이면 자연 정지(GameDirector 클록과 동기). 보스는 미구현.
- **밀도 성능(중요):** 대량 적에서 `EnemySimulation.FixedUpdate`(=`CrowdSolver.Step`)는 O(n×k). k가 밀도에 비례하면 초선형 폭증 → **장거리 예측 회피(`EnableLongRange`)를 끄면** 이웃 질의 반경이 `자기반경+maxR`로 축소(pad 제거), 그 반경 안엔 비침투로 ~20여 마리만 들어가 **k가 자연 상한** → 사실상 n에 선형. 씬 솔버: longRange=false, MainIterations=4.

## 8. 무기 / 빌드 (M8 빌드 다양성)

여러 무기를 동시에 보유하고 **무기별 특성(Trait)을 개별 강화**하며, 무기와 무관한 플레이어 강화(이속/체력/자석)는 별도 카테고리다. 레벨업 카드는 동적 풀에서 3택.

**업그레이드 = 무기별 특성(중요, 재설계됨)**
- 무기는 단일 '레벨'이 없다. 대신 **자신이 선언한 특성(`TraitKind`: 공격력/다발/쿨다운/탄속/관통/범위)을 각각 독립 강화**한다. 무기마다 지원 특성·상한·증가폭(`WeaponDefinition.WeaponTrait`)이 다르다(예: 범위는 오라/창/궤도엔 있고 단일 투사체엔 없음).
- 카드 예: `마력볼트 — 다발 +1`, `서리오라 — 범위 강화`. 같은 무기의 여러 특성이 한 번에 후보로 나올 수 있다(무기당 제한 없음).
- 패시브 = **무기 비종속만**(이속/체력/자석). 무기 영향 패시브(힘/쿨다운/범위/다발/탄속)는 폐지되고 무기 특성으로 흡수됨.
- **진화는 이번 설계에서 제외**(데이터 `evolvesInto`는 보존, 추후 재도입).

**구조 — 3축 조합(전달 × 조준 × 이동)으로 무기 개성을 만든다**
- `WeaponInstance` — 특성별 레벨 배열 + 발사 타이머. **유효 스탯 = 기본값 + Step×특성레벨** (전역 패시브 수정자 없음). `TotalUpgrades`=특성 레벨 합.
- `BuildState` — 보유 무기(최대 6)·패시브(최대 6). `UpgradePool`이 '무기×미만렙 특성' + 새 무기 + 플레이어 패시브 후보 생성 → `UpgradePicker`로 중복 없이 3택.
- `WeaponController` — 인벤토리 실행기. 무기별 타이머로 fireMode 분기 발사. 시작 무기 = 마력 볼트.
- **축1 전달(fireMode):** NearestProjectile / SpreadProjectile / AuraField / PierceLine / Orbital
- **축2 조준(`WeaponAimMode`):** Nearest(최근접) / MostInLine(직선 최다적중) / DensestCluster(밀집 방향) / LowestHealth(최저 체력). 순수 계산은 `WeaponAiming`(BestLaneIndex/DensestClusterIndex, 테스트됨).
- **축3 이동(`ProjectileMotion`):** Straight / Homing(조향) / Boomerang(왕복) / Ricochet(연쇄). `Projectile`이 매 물리 스텝 적용. 파라미터 = `WeaponDefinition`(HomingTurnRate/RicochetRange).

**기본 무기 8종**
| 무기 | fireMode | 조준 | 이동 | 동작 |
|------|----------|------|------|------|
| 마력 볼트 | NearestProjectile | 최근접 | 직선 | 안정적 기본기, 예측사격·LOS·벽충돌 |
| 추적 미사일 | NearestProjectile | 최근접 | **호밍** | 가장 가까운 적을 향해 조향(곡선) |
| 연쇄 도탄 | NearestProjectile | 최근접 | **도탄** | 명중 후 반경 내 다음 적으로 튕김(pierce=튕김수) |
| 부메랑 | NearestProjectile | **밀집** | **부메랑** | 밀집 방향으로 던져 왕복 2회 타격(통과) |

신규 3종(추적/도탄/부메랑)은 현재 진화형 없음(추후). 시작=마력 볼트, 카탈로그=서리오라·산탄·관통창·궤도·추적·도탄·부메랑.

**진화 5종 (기본 무기 만렙 + 요구 패시브 만렙 → 진화형으로 교체)**
| 진화 | 기본 무기 + 요구 패시브 |
|------|------------------------|
| 볼트 스톰 | 마력 볼트 + 다발(Amount) |
| 블리자드 | 서리 오라 + 범위(Area) |
| 플랙 | 산탄 + 탄속(Proj.Speed) |
| 임페일러 | 관통 창 + 힘(Might) |
| 헤일로 | 궤도 위성 + 재사용(Cooldown) |

**패시브 6종 (전역 수정자)**
| 패시브 | 효과 | 비고 |
|--------|------|------|
| 힘 Might | 데미지 +10%/레벨 | |
| 재사용 감소 Cooldown | 발사 간격 −8%/레벨 | |
| 범위 Area | 오라 반경/부채각 +12%/레벨 | |
| 다발 Amount | 투사체 +1/레벨(최대 3) | **볼트 스톰 진화 조건** |
| 탄속 Proj.Speed | 투사체 속도 +15%/레벨 | |
| 자석 Magnet | 자석 반경 +20%/레벨 | 플레이어 유틸 |

- **진화:** 무기 만렙 + 요구 패시브 만렙 시 진화 카드 등장 → 기본 무기를 진화형으로 교체(마력 볼트 + 다발 → 볼트 스톰).
- **공통:** 예측 사격(leadFactor 0.6) · LOS 차단(`ObstacleField.Blocks`) · 투사체 벽 충돌(거리 < 0.2 소멸).
- **VFX(무기별 구분):** 투사체=색+트레일, 오라=반투명 디스크, 관통=빔 플래시(LineRenderer), 궤도=회전 발광 오브+트레일. 색·크기는 `WeaponDefinition`(Color/VfxScale), 진화형은 강화. `WeaponVfx`(Player)가 오라/궤도 지속 비주얼을 BuildState에 동기화(진화/제거 시 정리). 머티리얼 `VfxAdditive`(가산)/`VfxDisc`(반투명). (사운드는 미구현)

## 9. 전투·사망·손맛(피격 연출)

- 데미지 단일 진입점 `DamageSystem`. 적/플레이어 공용 `Health`(`IDamageable`).
- 적 사망 → **사망 VFX**(VFX Graph `DeathPoof`, 풀링) + `EnemyDiedEvent` 발행 → 젬 스폰.
- **적 피격:** 흰색 플래시 + 스케일 펀치(`Enemy`가 per-instance MPB로, 인스턴싱 유지). 감쇠는 `EnemySimulation` 중앙 루프에서 틱(적별 Update 0개). 데미지 적용 시 `EnemyHitEvent`(실제 적용량·치명 여부) 발행.
- **데미지 숫자:** 피격 위치에 떠오르며 페이드하는 숫자(`DamageNumberLayer`, HUD UI Toolkit 패널 재사용·풀링·카메라 투영). 치명타는 주황·크게.
- **임팩트 VFX:** 비치명타 피격 지점에 가산 발광 스파크(`ImpactVfx`, 자체 풀·프레임당 캡). 치명타는 사망 VFX가 담당.
- **플레이어 피격:** 화면 가장자리 붉은 비네트(HUD). 강도는 `DangerMeter`(지수 감쇠)로 피격량에 비례 수렴 — 가벼운 접촉은 옅게, 다수에 둘러싸이면 진하게.
- 순수 로직(`HitReactState`/`DangerMeter`/`FloatingTextAnim`, `Core.Feedback`)은 MonoBehaviour와 분리해 단위 테스트.

## 10. 진행 (경험치·레벨·업그레이드)

- **경험치 곡선:** 다음 레벨 요구량 = `5 + (레벨-1)×3` (L1→5, L2→8, L3→11 …). 초과분 이월.
- **XP 젬:** 사망 위치 드랍 → 플레이어 pickupRadius 내면 자석으로 끌려와 흡수.
- **레벨업:** 일시정지 + **동적 3택**(중복 없음) → 선택 적용 → 재개. 다중 레벨업은 연속 카드.

### 업그레이드 풀 (동적)

고정 목록이 아니라 현재 빌드에서 매번 후보를 생성한다(8절 참조): **무기 특성 강화(UpgradeTrait) / 무기 신규 / 플레이어 강화 신규 / 플레이어 강화 레벨업**. 무기 특성은 해당 `WeaponInstance`의 특성 레벨에 누적, 플레이어 강화(이속/체력/자석)는 `RunStats`에 재반영된다. (진화 카드는 생성하지 않음.)

## 11. HUD (UI Toolkit + USS)

다크 + 금색 강조 팔레트. 스타일은 `Assets/_Project/UI/Hud.uss`(StyleSheet)로 분리, `HudController`가 코드로 트리 구성. PanelSettings = **Scale With Screen Size**(기준 폭 680 = 2.0× @1358). 메인 HUD는 카드 대비 0.8× 크기.

- **상단:** 레벨 뱃지(금색) + 전폭 **XP 바**(채움률) / 아래 줄에 **처치 수**(적색 점) · **타이머**(금색 점, mm:ss)
- **하단:** **보유현황 아이콘 줄**(무기=사각 칩, 숫자=**총 강화 횟수**(특성 레벨 합) · 플레이어 강화=원형 칩, 숫자=레벨, 색=무기색/종류색) + **HP 바**(체력 비율에 따라 녹→황→적, n/max)
- **레벨업 3택 카드:** 종류 라벨(무기·신규 등) · 색 아이콘(사각/원) · 이름 · 레벨 태그(Lv n / 신규 / 진화) · 설명. 무기색/패시브색 상단 테두리, **진화 카드 금색 강조**(리본+테두리). 호버 시 살짝 떠오름. 카드는 솔리드 패널.
- **결과 화면:** 승리=금색/패배=적색 대형 타이틀 + **요약 패널**(생존 시간·처치·도달 레벨 + 최종 빌드 아이콘) + 다시 시작.
- 피격 비네트(가장자리 붉은 띠)는 HUD 패널에서 그린다(9절).
